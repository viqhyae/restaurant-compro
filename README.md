# Barcook Gallery Company Profile Website

Premium one-page company profile prototype for Barcook Gallery.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- Next Image

## Sections

- Hero
- About Barcook
- Signature Menu
- Barcook Experience
- Gallery
- Visit Us
- Footer

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```bash
npm run build
```
